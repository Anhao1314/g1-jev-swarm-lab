# Experiments

Each reportable experiment should have a stable identifier and enough metadata to reproduce the comparison.

Planned categories:

- `baselines/` — deterministic and single-agent baselines;
- `jev/` — Jev decision studies;
- `swarm/` — multi-swarm studies;
- `long_horizon/` — mission-level evaluations.

Do not commit large checkpoints, raw videos, secrets, or transient logs here.
