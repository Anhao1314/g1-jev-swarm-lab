## Chosen small set

- Seen6m: nominal initialization / existing parent, for compatibility only.
- Turn45→Walk6: different true skill history, no new angle/controller/action profile; tests turning/settling influence on eventual stop state. Node-local actual frame prevents pretending initial world yaw offset is independent dynamics.
- Push60→Walk6: one fixed finite perturbation of the same parent; tests transient state influence after force ends. No random trigger or severity scan.
- One normal control: unchanged Walk4→Turn45→Stop, no failure halt/continuation request.

No simple new seed, XY translation or initial-yaw rotation is accepted as independence. No friction stratum is selected: friction would alter persistent environment/contact behavior, complicating state-only interpretation and current mission capability coverage. No joint sigma sampling, distance ladder, residual probe or independent held-out claim. These are predeclared mechanism conditions derived from seen source mechanisms; future outcomes are unknown and every cell is retained.

## Technical feasibility before future physics

Existing LiveMissionSession/run_node, DisturbanceProxy/PushSpec and force clear calls support the constructions without changing policy/controller inputs. An experiment-only wrapper must arm relative to captured first-Walk entry, retain actual start/end events, check all xfrc_applied zero before halt/assessment and release on errors. Future adapter must synchronize its pose observer, step count and current_state for the one deliberately stale-state tick. Same-session identity and native resets need existing M2.3b witnesses. Because old acquire.py hardcodes historical equality and successful halt, it is not used as a generic collector. Source hashes are pinned in source_manifest.json; official assets are not installed in the new design worktree and must be independently verified before acquisition.

This inventory supports a design, not demonstrated new states or reliable halt. Failure to reach the intended strict-trigger state remains missing coverage, with no replacement.
